# 发票查验查重及台账

## 使用说明

### Skill 功能介绍

本 Skill 用于：

- 发票真伪查验
- 发票重复风险检查
- 发票台账自动生成

您只需提供发票所在文件夹路径，系统即可自动完成发票识别、查验、查重及台账整理工作。

### 使用前准备

首次使用前，请先配置发票查验 API Key。

#### API Key 获取方式

1. 登录柠檬云AI财税开放平台，完成注册领取免费调用额度。→注册登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-API Key管理】页面
3. 创建并复制 API Key，发送给我，完成API Key配置（创建API Key时需要绑定【发票查验】权限）

### 获取帮助

如果您在安装或使用过程中遇到问题，请点击 {{OPEN_API_CONTACT_SERVICE_URL}} 扫码添加我们的专属客服企业微信联系我们。

API Key配置完成后，您可以直接告诉我：

“将【D盘】路径下的【发票文件夹】里的发票进行发票查验和生成发票台账”

我将帮您完成发票查验等操作。

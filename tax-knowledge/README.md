# 财税知识库

## 使用说明

### Skill 功能介绍

本 Skill 用于查询和解读财税政策：

- 税收政策依据查询
- 政策是否有效、是否废止
- 税收优惠适用条件分析
- 发票开具、进项抵扣、纳税申报相关政策咨询
- 涉税处理建议和风险提示

您只需告诉我需要咨询的财税政策问题，我将帮您查询相关政策依据并进行解读。

### 使用前准备

首次使用前，请先配置财税知识库 API Key。

#### API Key 获取方式

1. 登录柠檬云AI财税开放平台，完成注册领取免费调用额度。→注册登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-API Key管理】页面
3. 创建并复制 API Key，发送给我，完成API Key配置（创建API Key时需要绑定【财税知识库】能力）

### 获取帮助

如果您在安装或使用过程中遇到问题，请点击 {{OPEN_API_CONTACT_SERVICE_URL}} 扫码添加我们的专属客服企业微信联系我们。

API Key配置完成后，您可以直接告诉我：

“请帮我查询小规模纳税人开具增值税专用发票适用什么征收率，并提供政策依据”

我将帮您查询和解读相关财税政策。

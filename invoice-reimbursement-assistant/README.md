# 发票整理、查验及报销助手

## 使用说明

### Skill 功能介绍

本 Skill 用于自动收集、核验和整理发票：

- 自动从邮箱收集电子发票
- 发票真伪查验
- 发票自动分类整理
- 自动生成报销清单
- 发票归档管理

您只需完成邮箱授权配置，系统即可自动帮助您处理报销发票。

### 使用前准备

首次使用前，请先配置发票查验 API Key和邮箱授权配置。

#### API Key 获取方式

1. 登录柠檬云AI财税开放平台，完成注册领取免费调用额度。→注册登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-API Key管理】页面
3. 创建并复制 API Key，发送给我，完成API Key配置（创建API Key时需要绑定【发票查验】权限）

#### 邮箱授权配置步骤

1. 登录您需获取发票的邮箱网址
2. 获取邮箱授权码
3. 在使用时发送邮箱授权码给我，完成配置

### 获取帮助

如果您在安装或使用过程中遇到问题，请点击 {{OPEN_API_CONTACT_SERVICE_URL}} 扫码添加我们的专属客服企业微信联系我们。

API Key配置完成后，您可以直接告诉我：

“获取【XX邮箱】里的发票文件进行查验”

我将帮您完成提取邮箱的电子发票，并进行查验和生成报销清单等操作。

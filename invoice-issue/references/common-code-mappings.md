# 编码映射表

本文件定义自然语言与接口参数编码之间的映射关系。

## 省份/城市编码映射 (areaCode)

# 使用规则（⚠️ 必须严格遵守）

1. 当自然语言中提到省份或城市名称时，自动匹配以下映射表
2. **匹配规则（优先级顺序）**：
   - **第一步**：优先匹配地级市（如"深圳"→4403、"大连"→2102、"厦门"→3502、"青岛"→3702）
   - **第二步**：若未匹配到地级市，再匹配省份（如"广东省"→44）
   - **⚠️ 重要**：遇到地级市名称时，**必须**返回地级市编码，**不得**返回省份编码
3. 若匹配成功，将对应的areaCode作为参数值传入接口
4. 若未匹配到，提示用户补充
5. 仅对明确标注为"areaCode"参数的地名进行转换，其他字段保持原样

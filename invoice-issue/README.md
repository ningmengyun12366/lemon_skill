# 全场景开票

## 使用说明

### Skill 功能介绍

本 Skill 用于企业全场景智能开票：

- 单张开票
- ERP销售订单或电商订单批量开票
- 合同等资料开票
- 发票自动交付

支持多种开票场景，实现开票流程自动化。

### 使用前准备

首次使用前，请先配置发票开具 API Key和需开具发票的企业税务信息。

#### 企业税务信息设置

1. 登录柠檬云AI财税开放平台→登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-企业税务信息设置】页面
3. 新增企业，维护需开票的企业税务信息，完成配置

#### API Key 获取方式

1. 登录柠檬云AI财税开放平台，完成注册领取免费调用额度。→注册登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-API Key管理】页面
3. 创建并复制 API Key，发送给我，完成API Key配置（创建API Key时需要绑定【发票开具】权限及绑定需开票的企业）

### 获取帮助

如果您在安装或使用过程中遇到问题，请点击 {{OPEN_API_CONTACT_SERVICE_URL}} 扫码添加我们的专属客服企业微信联系我们。

API Key配置完成后，您可以直接告诉我：

给XXXXX公司，税号为XXXXXXXX，开具XXXX（商品名称）的普票（发票类型），金额是XXX元”

我将识别开票数据，并生成开具发票预览文件，待您确认无误即可完成开票并进行交付。

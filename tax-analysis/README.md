# 税务分析

## 使用说明

### Skill 功能介绍

本 Skill 用于自动获取企业财税数据，并生成企业税务风险分析报告，主要支持：

- 自动获取企业工商及税务基础信息
- 自动获取企业进销项发票数据、申报数据
- 识别税负异常、财务指标异常、税务异常等风险并生成风险分析报告

输入企业名称及时间范围后，系统将自动生成税务风险分析。

### 使用前准备

首次使用前，请先配置税务风险分析的 API Key 和进行税务风险分析的企业税务信息。

#### 企业税务信息设置

1. 登录柠檬云AI财税开放平台。→登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-企业税务信息设置】页面
3. 新增企业，维护需税务风险分析的企业税务信息，完成配置

#### API Key 获取方式

1. 登录柠檬云AI财税开放平台，完成注册领取免费调用额度。→注册登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-API Key管理】页面
3. 创建并复制 API Key，发送给我，完成 API Key 配置（创建 API Key 时需要绑定【税务分析】权限及绑定需进行税务风险分析的企业）

### 获取帮助

如果您在安装或使用过程中遇到问题，请点击 {{OPEN_API_CONTACT_SERVICE_URL}} 扫码添加我们的专属客服企业微信联系我们。

API Key 配置完成后，您可以直接告诉我：

“生成XXXXX公司近12个月的税务风险分析报告”

我将自动获取企业财税数据，完成数据统计、勾稽关系核对及风险识别，并生成可下载的企业税务风险分析报告。

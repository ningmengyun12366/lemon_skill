# 报告内容与计算范围

本页说明报告的章节内容、计算口径及数据范围，与[输出规则](report-output-v4.md)配合使用。原始申报表不作为报告附表。

## 章节及图表

- 1.1保留“风险等级／数量／主要领域”表；1.2只保留环图，删除两列重复表。1.4要求的总表和重点明细保留。
- 环图包含高、中、低及未见明显异常，以已完成的检查为分母；未完成及不适用不计入。高、中、低使用红、橙、黄。
- 1.5始终使用完整季度表头。各月风险发生次数、可确认金额按季度汇总，等级不能相加。缺少历史状态不补零、不表示恢复正常；年度或历史所属期记录不能硬分配到某个本期季度。
- 4.2保留完整月份和合计；季度申报归入季末月份，年度汇算单独列示且不计入月度合计。只展示实缴金额数字，统一元、两位小数；没有实缴记录不以申报金额补填。完整所属期仍保存在底稿。
- 4.6收入取数口径：月报取指定增值税累计栏还原单月收入；季报优先同期利润表，未申报同期利润表时取指定增值税累计栏还原单季收入。按实际月/季所属期对齐税费，缺数不补零、不均摊，见[输出规则](report-output-v4.md)。
- 5.5按实际所属期展示单月/单季：财报按准则还原当期，与同期增值税销售额比较；6.2、6.4使用可还原的同季数据。期末留抵取季末余额，不能把月末余额相加；年度财报/汇算单列，不能构成“第五季度”。
- 8.6仅汇总已有财务事实和关键限制，不生成零风险占位卡或额外指标表。9.5为固定节，缺行业基准时只隐藏雷达和对标结论。
- 8.2趋势列及8.3变化列展示相邻同周期的实际百分点变化；年度只与上一年度比较，缺少相邻期间不跨期比较。研发费用是否包含在管理费用的说明单独列示，不填入趋势列。

## 数据与报告范围

- 发票基础记录及其金额正负号按[数据契约](report-data-contract.md)解释。数电票关联优先使用有效的`sdphm`，`fphm=0`不是可用票号。客户、供应商及公开信用章节的交易占比均使用同一发票分母。
- 红字输出数量、绝对金额、红字金额与蓝字金额之比、主要品类及客户；不附全量红字票明细。Top业务饼图补“其他”，不能把Top3小计归一化成全企业收入。
- 购销比较按业务品类关联，不按金额排行配对。品类和经营范围的文字命中只说明已知匹配线索，不能据此认定所有开票业务符合经营范围。
- 3.13分别核对抬头税号、品名编码、税率及异常主体/凭证，明确字段和判断覆盖范围。缺交易适用条件、历史身份或权威分类依据时，不得宣称匹配正确或整体合规。3.14取数未取得备注/特定字段时使用数据说明，不把缺少取数当成原票异常。
- 5.6列明未开票、红字、固定资产处置及视同销售汇总；未取得单独字段不写零。5.7仅输出异常凭证、不得抵扣项目、进项转出、勾选与申报差异四类检查。独立异常凭证列表必须纳入；状态冲突、勾选和最终申报抵扣不能混同。
- 5.9只输出免税、简易、差额征税适用情况及有发生额的税率。6.5—6.8输出主要调整、研发季年汇总、实际优惠及主要扣除凭证线索；不重复累加父子项、季度累计与年度总额，数量不能进入金额。
- 纳税调整等汇总保留税局原中文项目名，不能将以“（三）”“（八）”等序号开头的实际业务名称清空。
- 7.4汇总附加申报、同属期主税基础、比例及实缴，说明适用税率/减征；7.5比较同口径申报和实缴趋势，工资基数缺失不由其他税种反推。
- 不增加5.1累计辅助表、5.5/8.4预收辅助表、税局原始字段表、逐条复算和逐笔缴款附表。原始`taxFields`、`calculations`和取数路径继续保存，便于复核；不把这些证据直接贴入正文。
- 同一缴款记录不重复计入，历史所属期要明确说明。申报异常保留税局给出的实际税费种及完整所属期，不猜测税种或归入起始月份。

## 文字与交付检查

普通事实可不填写说明。关注只说明事实及其意义；数据不足只说明缺什么、不能判断什么。只有已确认风险才给对应动作，第十章不增加其他事项。不能以某几个检查未命中扩写成整个发票、财务或税费领域正常。

“一致”必须有可比主体、期间、税种、口径和数值证据；“逐季改善、持续上升”等必须对应完整可比序列。可信引用存在不代表关系成立。比例引用保留百分号，禁止把右轴比例当金额或再次乘100。

交付前检查本次DOCX与PDF的内容、目录链接和页面布局，确认企业、期间、金额及风险表述一致，文字和表格完整可读。

# 报告输出规则


本页说明报告的内容、数据口径、分析状态与版式要求。填写正文前先读本文件，再读工作区analysis-task.md。

## 全税种税负率月季口径

4.6按增值税实际申报周期计算和展示，月报显示月轴，季报显示季度轴，周期变更时保留各自真实所属期；不因只取得季度财报就把月报企业改为季报。

- 月报：按增值税主表第（1+5+7+8）栏，一般项目与即征即退项目的本年累计数合计，扣减紧邻上月累计数还原单月收入。
- 季报：优先同期利润表营业收入；只有累计收入时扣减紧邻上季累计数还原单季。未申报同期利润表时，按增值税主表第（1+4+7+9+13+15）栏，货物及劳务与服务、不动产和无形资产的本年累计数合计还原单季收入。已申报但收入缺失或明确为零时不得换来源规避缺口。主表0A00“全部销售额”仅提供本期数时，使用该本期数。
- 累计还原不跨年、不跳过缺失前期；年报不替代第四季度，不平均拆分季度收入，不使用开票额代填。税费按真实所属期结束月份归入对应月/季，只有缴款日期而无法确认所属期的记录不用于税负率计算。
- 两个系列仍为企业自身综合税负率、全税费缴纳率。无缴款记录、缺少同期收入、收入为零或所属期不完整时显示缺口，不补零；实缴明确为零可计算0.00%。超过18个月按自然年拆图，每张图保持实际申报周期。

使用已提供的收入分母、剔除代扣代缴后的税费、全部税费、税负率、前3个连续可比期均值及相对偏离，解释可比期间及集中缴税影响。基期不足不套用前3期规则，不自行推定风险或新增阈值。字段明细及计算底稿不贴入成品正文。

## 表格展示

企业变更信息有记录时只展示完整表格，不显示时间轴或无数据占位图；保留全部记录及原始顺序。税费月度汇总只展示实缴金额，单元格为元、两位小数，不拼接“申报/实缴”标签或双份金额；行合计、税种合计及总计均只累计实缴。实缴为零显示0.00，没有实缴记录显示“—”，不得用申报额代填。季度记录归入季末月份，年度汇算单独列示；仅有缴款日期时明确说明。

全税种税负率按前述月/季口径计算。

## 量化分析与来源记录

按[逐节分析规则](report-analysis.md)使用本批指标、分析目标及范围，生成自然语言text并在evidenceRefs独立留存来源。技术校验检查结构、引用ID和冻结摘要，通过后直接渲染；不要求单独语义审读或正文复述证据。

维持四个指定章节不加说明；其他DESCRIPTION可空，但已有充分证据支持的必需分析目标不能被省略。量化用于说明实际对象、期间、金额、比例、差异和范围，不能编造管理目标或整改时限。

## 企业变更全部展示

企业变更信息必须完整展示企业自身已取得的全部工商变更记录，包括报告期前后记录，不受税务任务2017年起或最长三年范围限制。保留来源顺序、同日多条及重复记录；日期不能识别时展示原值，日期缺失显示“未获取”，不能丢弃整条。日期、事项、变更前、变更后、关注逐条对应；历史变更本身不推断补税或新增风险。

明细表展示全部记录，不截成前6条或TopN；不生成时间轴。成功返回空变更集合时仅写“未查询到企业变更记录。”；确实未取得变更数据时才使用数据说明。不要添加重复读表的说明段落。

企业变更展示范围独立于税务分析期间。

## 指定章节与封面

2.1工商基本信息、2.2股东及出资、2.3股权穿透及疑似关联方、3.1发票总体情况：有数据时只展示表格/图表，不另加“说明”标题及复述段落。DESCRIPTION的maxItems固定为0，不加入Agent文字填写列表；不得改名为“概述”“小结”绕过。表格内的说明列保留，真实风险及缺数/样本覆盖提示继续按原证据规则处理。

封面只填写企业名称、报告期间、生成时间等既定内容，不添加额外的金额单位说明。

## 六种主状态

状态由脚本决定，英文编码不显示在报告中。

| 状态 | 可见内容 | 文字边界 |
|---|---|---|
| DESCRIPTION | 表格/图表；必要时说明 | 0—2点，允许空items，不重复读表 |
| ATTENTION | 关注事项 | 1—3点，不升级风险，不给整改建议 |
| RISK | 风险分析和整改建议 | 各1—3点，表述简洁易懂，风险与动作对应 |
| DATA_INSUFFICIENT | 数据说明 | 一段，缺什么、不能分析什么，到此为止 |
| NOT_APPLICABLE | 说明 | 一句，不放空表或建议 |
| NO_ISSUE | 默认不追加文字，必要时说明 | 最多一句，所需数据必须完整 |

固定文案后不自由扩写。风险概览不再强制三条重复读图。每点提供新的事实、必要口径/限制、关键变化、风险影响或具体动作；否则省略。

## 数据与判断

- 缺失不等于0，查询成功空数据不改成请求失败，也不意味着具有计算指标所需数据。
- 发票月份须与增值税申报销售月份核对。覆盖不足时，客户、集中度、业务结构和行业只描述已取得样本；sampleOnly小节如填写文字，必须引用本节dataNotice，不能概括企业整体。
- 年度/月度金额与Top交易方合计应勾稽，不能通过去重、丢记录或改正负号凑平。不一致停止相关判断。
- 票申差额不直接等于未开票收入、漏报或异常；小规模展示“票申差额”，保留原计算；一般纳税人直接取附列一未开具发票销售额。口径、红冲和跨期解释不足时不得定性。
- 财报按指标所需报表、字段和期间检查。缺少无关财报不影响只依赖增值税申报表的指标；分母为0或缺失不计算比率。
- 精确匹配主体才可判断公开信用；未形成风险不等于没有历史记录，真实事实仍保留。
- 跨年红冲须有完整窗口、金额与原蓝票关联；不能补造比例或等级。
- 房土税源为空不否定实际申报或缴款，不从地址、租赁或经营范围推定纳税义务。所得税年度明细缺失不扩写招待费、广告费和优惠的潜在问题。

## 固定文案使用

以下固定文案中的变量必须替换为实际业务名称，不得原样进入报告。只有已取得相关查询及覆盖证据才可使用“无事项”；没有数据不能说正常。

| 场景 | 产品固定文案 |
|---|---|
| 未见明显异常 | 说明：基于本期已取得的数据，未发现明显异常。 |
| 数据未取得 | 数据说明：本期未取得{数据名称}，暂无法分析{分析事项}。 |
| 数据覆盖不完整 | 数据说明：本期取得的{数据名称}覆盖不完整，以下内容仅反映已取得数据，不能代表企业整体{分析对象}。 |
| 期间不足 | 数据说明：本次分析期间未覆盖{所需期间}，暂无法进行{分析事项}。 |
| 主体未精确匹配 | 数据说明：未取得与{主体名称}精确匹配的工商信息，因此不对该主体的公开信用情况作判断。 |
| 无红字发票 | 说明：本期未识别到红字发票。 |
| 无敏感服务类发票 | 说明：本期未识别到需要重点关注的敏感服务类发票事项。 |
| 无疑似虚开销项线索 | 说明：本期未识别到疑似虚开销项发票的明显线索。 |
| 无疑似虚假进项线索 | 说明：本期未识别到疑似取得虚假进项发票的明显线索。 |
| 无申报更正/逾期/欠税 | 说明：本期已取得的申报及缴款记录中，未发现申报更正、逾期申报或欠税记录。 |
| 无税务处罚/重大违法 | 说明：本期查询到的公开信息中，未发现企业税务处罚或重大税收违法记录。 |
| 无行政处罚/经营异常 | 说明：本期查询到的公开信息中，未发现企业行政处罚、经营异常或严重违法失信记录。 |
| 研发费用无数据 | 数据说明：本期未取得研发费用申报数据，暂无法分析研发费用申报情况。 |
| 企业所得税优惠无数据 | 数据说明：本期未取得企业所得税年度优惠申报明细，暂无法分析优惠项目及申报金额。 |
| 印花税无数据 | 数据说明：本期未取得印花税申报或缴款数据，暂无法分析印花税申报缴纳情况。 |
| 房产税无数据 | 数据说明：本期未取得房产税税源、申报或缴款数据，暂无法分析房产税情况。 |
| 土地使用税无数据 | 数据说明：本期未取得城镇土地使用税税源、申报或缴款数据，暂无法分析城镇土地使用税情况。 |
| 工会经费无数据 | 数据说明：本期未取得工会经费申报或缴款数据，暂无法分析工会经费情况。 |
| 财务报表无数据 | 数据说明：本期未取得完整的税务报送财务报表，暂无法开展财务指标分析。 |
| 跨年红冲期间不足 | 数据说明：本次分析期间未覆盖年末开票及次年红冲所需的完整期间，暂无法进行相关分析。 |
| 小规模-进项抵扣 | 说明：企业当前为小规模纳税人，不涉及一般计税项目的进项抵扣分析。 |
| 小规模-留抵税额 | 说明：企业当前为小规模纳税人，不涉及一般计税项目的留抵税额分析。 |
| 无实际风险 | 第十章“风险整改建议”整章不展示，不输出任何占位文案。 |

## 文风及最终检查

所有正文面向企业老板或财务人员，不出现本规则、本项规则、规则库、规则实例、组合规则、检测实例、模型、AI、接口、置信度或内部字段串。不得猜备货、扩张、春节、资金压力、项目延期、经营困难；不写没有对象和事实的加强管理、持续关注。避免风险敞口、闭环、赋能、抓手等包装词。

正文直接进入Word/PDF，不自动拼入引用原文。生成时保持中文表达清楚、避免双标点、套话或重复读表；真实企业和商品名称保留原值。脚本不对这些自然语言要求设置字数或关键词门槛。底稿和校验记录留在本地工作区。

## 结论、整改与版式

conclusion.items为3—5条重点：首条总体风险，随后1—3项优先风险及对应动作，按必要性保留最重要的数据限制或其他客观事实。不强制凑齐四种类别，不重列所有缺口。风险标题与recommendation引用须在同一点关联。风险明细按本节findingIds前3项逐条写分析，与脚本同序的整改动作对应；其余风险仍在第十章列齐。

无确认风险隐藏第十章；有风险只列实际处理和跟踪。明细节内最多三条动作，其余风险在第十章列齐。关注、缺数和正常结果都不能输出整改建议。未确认风险但数据不足时，不得称企业完全正常。

财报整体缺失，第八章只留一条数据说明；行业品类全缺时隐藏行业子节。小规模5.7/5.8各保留一句不适用说明，无空表。

Word/PDF的章节、目录、数值和风险必须一致。封面无页眉；正文页眉左企业名称、右财税风险分析报告，同字号、同基线、同颜色。风险高/中/低为红/橙/黄，关注蓝/灰，数据说明灰色。标题不孤立、表头跨页重复、单行不拆分、数量使用整数格式。

交付前检查本次Word和PDF的正文、表格、图表、目录链接和页面布局，确认状态说明与已取得的数据一致，内容完整可读。

综合风险评价保留指标统计、去重主题等级表与综合卡片；覆盖不足时卡片显示“综合判断受数据覆盖限制”，已有检测统计仍保留。综合等级与最高单项等级分别处理。概览判断依据只给期间范围、合计和处理状态，不重复整年逐月明细；企业变更仍完整表格展示。

8.3–8.6有可用指标时给出量化分析，未知期间明确保留。表格先保证能容纳的表头单行，再为完整金额/日期预留宽度，最后分配长名称与正文空间；不得截去企业变更记录或短金额尾数。

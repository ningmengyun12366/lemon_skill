# 报告章节与展示要求


> 当前交付约束见[输出规则](report-output-v4.md)，报告规则 `{{REPORT_RULE_VERSION}}`，AI契约 `{{AI_CONTRACT_VERSION}}`。字段及来源以[数据契约](report-data-contract.md)为准。

生成报告时按下表确定章节标题、图表、表头和显示条件；展示样式不得改变报告内容。

## 全局约束

- 章节标题必须逐字使用下表名称，仅按实际期间、客户/供应商数量、申报周期和 Top1-Top3 业务名称动态替换。
- 未指定图表的章节不生成图表。指定图表无数据时只能展示同类型无数据状态，不得更换类型或补造数据。
- 表头必须逐字、逐列、按顺序匹配。缺数及不适用按输出规则使用固定短文，不保留空表。
- 可见成品不得出现规则 ID、阈值、公式、评判标准、置信度、接口字段名或开发说明。
- `分析`由 Agent 填写；`整改意见`仅可由已确认风险的可信建议生成。未见明显异常、关注或数据不足不得生成整改意见。

## 视觉要求

- 图表主色：`#3D7FFF`、`#28B950`、`#F86602`、`#F7B500`。
- 高、中、低风险：`#FF3333`、`#FF991E`、`#FFCE45`。
- 表头背景：`#EFF2F7`；高风险单元格：`#FFF5F4/#B42318/#F97066`；中风险：`#FFF8EB/#B54708/#FDB022`；低风险：`#FFFDF0/#8A6100/#F4C95D`；未见明显异常：`#F1FAF5/#1F6F46/#62C28B`。

- DOCX/PDF 的内容、图表数据与样式必须一致。

## 补充数据与附表范围

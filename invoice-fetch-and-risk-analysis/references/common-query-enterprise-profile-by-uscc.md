# 独立查询企业画像

本命令用于没有取票任务时的独立企业画像查询。已有取票任务时必须执行 `fetch-deduction --task-file <task.json>`，不能用独立查询代替勾选步骤。

## 调用方式

先完成本 Skill 的预检，使用本次用户明确提供或选择的企业税号：

```powershell
& ".\bin\windows-amd64\invoice-assistant_windows_amd64.exe" query-enterprise-profile-by-uscc --uscc "<纳税人识别号>"
```

只需提供 `--uscc`，不从历史企业或工作区猜测本次查询对象。

## 返回结果

- `taxpayer_type`：纳税人类型，按实际结果展示为一般纳税人、小规模纳税人或待人工核验。
- `business_scope`：经营范围；缺失时说明尚未取得，不补造行业结论。
- 命令失败、权限不足或版本过低时，先按 [error-handling.md](error-handling.md) 处理；不要把失败当成企业没有相关信息。

独立查询普通失败或字段缺失时，可在有可用检索工具的情况下补充企业公开资料，并单独标注来源及未核验范围；不能声称这些资料由命令返回，也不能根据没有查到一般纳税人证据就判定为小规模。无法完成核验时请用户提供资料或在适用的税务查询页面确认。

## 交付

展示实际取得的纳税人类型和经营范围；部分完成时明确缺少哪些字段。只陈述核验结果和下一步，不输出请求报文、凭据或程序处理过程。

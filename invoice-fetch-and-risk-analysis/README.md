# 发票获取及风险分析

## 使用说明

### Skill 功能介绍

本 Skill 用于发票获取、数据统计及税务风险分析：

- 自动从税局获取发票数据
- 数电发票附件归集
- 发票多维度统计分析
- 风险分析报告生成

输入企业名称及时间范围后，系统将自动完成发票归集与风险分析。

### 使用前准备

首次使用前，请先配置发票批量获取 API Key和获取发票的企业税务信息。

#### 企业税务信息设置

1. 登录柠檬云AI财税开放平台→登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-企业税务信息设置】页面
3. 新增企业，维护需取票的企业税务信息，完成配置

#### API Key 获取方式

1. 登录柠檬云AI财税开放平台，完成注册领取免费调用额度。→注册登录地址：{{OPEN_API_PAGE_URL}}
2. 进入【控制台-API Key管理】页面
3. 创建并复制 API Key，发送给我，完成API Key配置（创建API Key时需要绑定【发票批量获取】权限及绑定取票的企业）

### 获取帮助

如果您在安装或使用过程中遇到问题，请点击 {{OPEN_API_CONTACT_SERVICE_URL}} 扫码添加我们的专属客服企业微信联系我们。

API Key配置完成后，您可以直接告诉我：

“获取XXXXX公司的YYYY年XX月份至YYYY年XX月份的发票数据，并进行风险分析”

我将帮您从税局获取发票数据，并生成发票风险分析报告等操作。
